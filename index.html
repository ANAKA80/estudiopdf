Estúdio PDF

Editor de PDF que funciona offline: seus arquivos nunca saem do computador.

Baixar para Windows .exe Baixar para Mac .dmg

Sempre a versão mais nova.

Como instalar
  1. Windows: abra o arquivo baixado. Se aparecer “O Windows protegeu o computador”, clique em Mais informações › Executar assim mesmo.
  2. Mac: abra o .dmg e arraste o Estúdio PDF para a pasta Aplicativos. Depois, ejete o disco “Estúdio PDF” no Finder (⏏).
  3. Depois de instalado, o app avisa sozinho quando sai versão nova.

Os arquivos vêm direto da página oficial de versões.
